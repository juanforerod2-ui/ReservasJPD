# Sistema de Reservas - Citas Médicas
Programa de consola en Python para gestionar citas médicas básicas: agendar, consultar disponibilidad, ver y cancelar reservas.
------------------------------------------------------------
## como funciona
- Agendar una nueva cita (paciente, médico, fecha y hora)
- Buscar disponibilidad de un horario específico
- Ver todas las reservas agendadas
- Cancelar una reserva por ID
------------------------------------------------------------
### Como ejecutar
    py reservas.py
------------------------------------------------------------
### Menu
1. Agendar cita
2. Buscar una reserva disponible
3. Ver mis reservas
4. Cancelar una reserva
5. Salir
